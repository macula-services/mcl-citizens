# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- The scaffold, generated by `rebar3 new mcl_service`: an OTP release that
  boots on `mcl_om`, joins the mesh, and answers `/health` on 8486.
- The citizens directory, ported from `hecate-citizens`:
  `mcl-citizens/register_presence`, `list_citizens` and `get_citizen`, all
  open, replacing `hecate_citizens.*`.
- Federation through the `citizen_presence_registered_v1` app fact, admitted
  only from verified publishers on `MCL_CITIZENS_PRESENCE_PUBLISHERS`.
- The start refuses a `MCL_REALM_NAME` whose sha256 is not `MCL_REALM`.
- `/health`: down without the directory, degraded while federation is not
  subscribed.
- `rebar3 dialyzer` in CI, with macula in the PLT so the `macula_response`
  callbacks are checked.

### Changed from hecate-citizens

- The registered citizen is the CALL's verified caller. The in-payload Ed25519
  ownership proof is gone: macula 12 signs and verifies every CALL end to end,
  and `macula_identity`, which the proof used, no longer exists.
- The directory is in memory (ETS) instead of a barrel_docdb read model on
  disk. It is soft state that expires within twenty minutes; after a restart
  it refills within one republish interval. Admission and write are one step
  in the directory's owning process, and a sweep removes expired entries.
- The federated fact is a canonical app fact and carries no hecate name.
- The migration clause for entries stored before `registered_at` existed is
  gone, since nothing is carried over.
- `Containerfile` building an alpine image, with macula's QUIC NIF compiled from
  source rather than fetched against a foreign libc.
- `deploy/docker-compose.yml`, the service's own run contract.
- CI: `lint-and-test` on every push and pull request, `build-and-push` to
  the registry: `:latest` on `main`, the semver tag alone on `v*`.
